Интеграционный шлюз Bitrix24 ⇄ 1С:Бухгалтерия 8.3

Исходные коды и конфигурационные файлы для выпускной квалификационной работы.
Автор Догадин Д.Д. (группа БИ-41)

Описание проекта
Проект представляет собой отказоустойчивую систему автоматического обмена данными (Order-to-Cash) между облачной CRM и локальной учетной базой, скрытой за NAT.

Архитектура решения
* Сетевой уровень: Nginx Reverse Proxy + Cloudflare WAF.
* Транспортный уровень: VPN-туннель WireGuard (L3-маршрутизация).
* Учетная система: HTTP-сервис на платформе 1С:Предприятие 8.3.

Содержимое репозитория
* `/Инфраструктура/wg0.conf.txt` — конфигурация VPN-сервера WireGuard.
* `/Инфраструктура/bitrix-proxy.txt` — конфигурация обратного прокси-сервера Nginx.
* `ИнтеграцияБ24.cfe` — расширение конфигурации 1С.
* `http_service_module.bsl` — исходный код HTTP-сервиса (парсинг JSON, бизнес-логика, генерация HTML-уведомлений).
